# 게임 기획서: Flappy Bird (SolidJS + Canvas)

## 1. 개요
플래피 버드는 플레이어가 새를 조종하여 파이프 장애물을 피해 최대한 멀리 이동하는 중독성 있는 아케이드 게임입니다.

## 2. 게임 메커니즘

### 2.1 플레이어 (Bird)
- **속성**: 위치(x, y), 반경, 속도(velocity), 중력(gravity), 점프력(jump strength).
- **동작**:
  - 화면을 클릭하거나 스페이스바를 누르면 위로 점프합니다.
  - 점프하지 않을 때는 중력에 의해 아래로 추락합니다.
  - 화면 상단이나 하단에 닿으면 게임 오버됩니다.

### 2.2 장애물 (Pipes)
- **구조**: 위/아래 두 개의 파이프가 한 쌍을 이루며, 그 사이에 새가 지나갈 수 있는 간격(Gap)이 존재합니다.
- **생성**: 일정 시간 또는 일정 거리 이동 시마다 새로운 파이프 쌍이 화면 오른쪽 끝에서 생성됩니다.
- **이동**: 모든 파이프는 일정한 속도로 왼쪽으로 이동합니다.
- **충돌**: 새의 히트박스가 파이프 영역과 겹치면 게임 오버됩니다.

### 2.3 배경 및 환경 (Background & Environment)
- **패럴랙스 스크롤링 (Parallax Scrolling)**:
  - Distant Layer: 구름 및 산언덕 (가장 느린 스크롤 속도 `0.15px/frame`)
  - Middle Layer: 도시 건물/중간 배경 (중간 속도 `0.45px/frame`)
  - Foreground Layer: 화단과 점선 무늬 지면 (게임 기본 속도와 1:1 동기화)
- **동적 난이도**: 점수 획득에 따라 점진적으로 속도가 증가하며, 파이프 생성 주기가 짧아집니다 (상세 난이도 매트릭스는 아키텍처 문서 참조).
- **동적 기상 및 바람 시스템 (Dynamic Weather System)**:
  - 게임 플레이 중 18초 간격으로 `맑음(Sunny) -> 비(Rainy) -> 눈(Snowy)` 날씨 중 하나가 무작위로 선택되어 전이됩니다.
  - 날씨 변경 시 화면 중앙에 경고 텍스트 알림(예: "RAINY WEATHER! HEAVY FEATHERS! (Gravity +15%)")이 파티클 텍스트로 화려하게 출력됩니다.
  - 날씨 상태에 따라 새의 동작(물리 움직임)이 물리 법칙에 의거하여 직접적인 영향을 받습니다:
    - **바람 (Wind Force)**: 비와 눈 상태일 때 6초마다 무작위로 바람의 세기와 방향($\pm 0.8 \sim \pm 1.6$)이 결정됩니다. 바람 외력에 의해 새가 수평 방향으로 출렁이며 밀려나며, 새는 원래 기준 위치($x=80$)로 돌아가려는 스프링-댐퍼 날갯짓 제어 시스템에 의해 서서히 복원 조율됩니다.
    - **비 (Rainy)**: 빗방울이 깃털을 적셔 유효 무게가 가중되므로 평소 대비 **하향 중력이 15% 증가**하여 낙하 속도가 빨라집니다.
    - **눈 (Snowy)**: 혹한의 눈보라로 인해 **점프 추진력이 8% 둔화**되고, 폭설 난기류가 매 프레임 수직 속도에 미세 무작위 외력(백색 소음)으로 작용하여 비행이 불규칙하게 흔들립니다.
  - 우측 상단에 날씨 상태와 풍향 화살표(예: `🌧️ ←`, `❄️ →`, `☀️`)가 실시간으로 렌더링됩니다.
- **피버 게이지 및 피버 타임 (Fever Gauge & Fever Time)**:
  - 파이프 통과(Good: +2%, Perfect: +12%), 코인 획득(+2%), 보스 타격(+1%), 보스 쉴드 충돌(+5%), 아이템 획득 시 피버 게이지가 누적됩니다.
  - 게이지가 100%에 도달하면 5초간 자동으로 무적 피버 모드가 활성화됩니다.
  - 피버 모드 시 화면의 모든 파이프가 사라지고 무지개 배경 연출과 함께 코인들이 대량으로 뱀 형태의 상하 물결 패턴을 이루며 화면에 쏟아집니다. (Plum 캐릭터는 즉시 5초 피버 및 코인 2배 효과를 쿨타임 스킬로 사용 가능)
- **랜덤 아이템 박스 (Item Box)**:
  - 파이프가 생성될 때 20% 확률로 빈 공간(Gap)에 선물 상자가 생성됩니다.
  - 획득 시 5초 동안 다음 버프 효과 중 무작위 하나가 활성화됩니다:
    - **자석(Magnet)**: 150px 반경 내의 코인을 자동으로 끌어당겨 획득.
    - **쉴드(Shield)**: 캐릭터 외부의 보호 구체를 생성하여 파이프 충돌이나 보스 공격을 1회 완벽히 무효화.
    - **코인 2배(Double Coin)**: 획득하는 모든 코인의 보상이 2배로 가산되어 저장.
    - **피버 드링크(Fever Drink)**: 피버 게이지가 즉시 20% 충전됨.

### 2.4 캔디 자이언트 보스 레이드 (Candy Giant Boss Raid)
- **스폰 조건**: 플레이어의 누적 점수가 15점씩 추가로 증가할 때마다(15점, 30점, 45점...) 일반 파이프 생성이 일시 중단되고 경고 문구 연출과 함께 `BOSS_FIGHT` 단계에 진입합니다.
- **보스 공격 패턴**: 보스 캐릭터가 화면 중앙부에서 호버링하며 1.5초마다 플레이어 캐릭터의 좌표 벡터를 정확하게 조준한 조준탄 발사체를 쏘아 보냅니다.
- **플레이어 반격 및 조작**:
  - `BOSS_FIGHT` 모드에서는 화면을 클릭하거나 스페이스바를 누를 때마다 새가 위로 도약함과 동시에 전방으로 캔디 미사일(`PlayerMissile`)을 발사합니다.
  - 미사일이 보스의 본체(히트박스 40px)를 타격하면 보스에게 4의 대미지를 줍니다.
  - 플레이어가 쉴드 상태에서 보스 몸통과 직접 충돌하거나 날아오는 보스 탄환(BossBullet)을 쉴드로 방어할 시, 쉴드가 깨지면서 보스에게 15의 폭발/반사 대미지(Shield Slam)를 입히고 1.2초간 무적 상태가 됩니다.
  - 플레이어가 망고(Honey Rush) 무적 대시 중일 때 보스 본체와 충돌하면 보스에게 20의 큰 대미지를 주며 대시와 오프셋이 즉시 안전하게 해제되고 1.2초의 안전 무적 시간이 부여됩니다(Dash Slam). 대시 중에는 보스 탄환에 맞더라도 피해를 입지 않는 완벽 무적이 적용됩니다.
  - 플레이어가 체리(Candy Blast) 스킬을 사용할 시 화면 상의 모든 보스 조준탄을 소멸 파티클로 폭발시키며 보스에게 12의 큰 광역 대미지를 입힙니다.
- **격퇴 및 전리품**:
  - 보스의 체력 100이 모두 0이 되면 보스가 폭발하며 그 자리에 25개의 스타 코인을 원형으로 흩뿌립니다.
  - 스폰된 25개의 전리품 코인은 플레이어의 캐릭터 자석 사양과 무관하게 강력한 인력(최대 350px 반경)에 이끌려 전부 자동으로 플레이어에게 흡입됩니다.
  - 격퇴 즉시 원래 일반 플레이 모드로 안전하게 돌아가며, 돌아온 시점에 파이프 타이머가 리셋되어 유저가 바로 스폰된 파이프에 부딪히는 불상사를 예방합니다.


## 3. 기술적 구현 상세

### 3.1 물리 엔진
- `velocity += gravity * timeScale`
- `position.y += velocity * timeScale`
- **회전 효과**: 속도에 비례하여 새의 각도를 -45도에서 90도까지 회전시켜 역동성을 부여합니다.
- **가변 타임스텝**: `deltaTime`을 활용하여 프레임 레이트와 독립적인 물리 연산을 수행합니다.

### 3.2 사운드 합성 (Sound Synthesis)
- **Web Audio API** 활용:
  - Jump: Square Wave (200Hz -> 600Hz)
  - Score: Sine Wave (800Hz -> 1200Hz)
  - Hit: Sawtooth Wave (150Hz -> 40Hz)

### 3.3 렌더링 및 UI
- **절차적 드로잉**: 모든 그래픽 요소는 Canvas API의 `arc`, `ellipse`, `linearGradient`, `radialGradient`를 사용하여 런타임에 그려집니다.
- **SolidJS 통합**: 게임 상태(READY, PLAYING, GAME_OVER)와 점수를 SolidJS Signal로 관리하여 UI와 엔진을 동기화합니다.
- **입력 필터링**: 리더보드 이름 입력 시 게임 조작이 간섭받지 않도록 이벤트 대상을 검사합니다.

## 4. 상태 관리
- **READY**: 게임 시작 전, 클릭 대기 중.
- **PLAYING**: 게임 진행 중, 점수 카운트.
- **GAME_OVER**: 충돌 후 결과 화면, 재시작 대기.

### 5. 점수 및 리더보드 시스템
- 파이프 쌍을 완전히 통과할 때마다 점수가 1점씩 올라갑니다.
- 최고 점수(High Score)를 로컬 스토리지에 저장합니다.
- **리더보드 (Leaderboard)**:
  - 새로운 최고 기록(Top 5) 달성 시에만 이름 입력 폼이 나타납니다.
  - **서버 연동**: Hono API (`/api/leaderboard`)를 통해 전역 랭킹을 관리합니다.
  - **오프라인 로컬 순위표**: 네트워크 연결이 원활하지 않을 때에는 브라우저 로컬 스토리지(`flappy-local-leaderboard`)에 상위 5개의 성적을 기록하고 영구적으로 보존하여, 오프라인 모드에서도 플레이 경쟁을 유기적으로 이어 나갈 수 있도록 지원합니다.

## 7. 사용자 경험(UX) 개선 및 디테일 보완 (UX Enhancements & Bugfixes)

### 7.1 게임 오버 화면에서의 클릭 미스 방지
- **입력 필터링 세분화**: 기존에는 게임 오버 상태일 때 화면의 어떤 위치(캔버스 영역)를 클릭하더라도 즉시 게임이 재시작되었습니다. 이로 인해 리더보드에 닉네임을 등록하거나 상점 버튼을 누르려다 실수로 다른 영역을 클릭해 게임이 원하지 않게 다시 시작되는 현상이 발생했습니다.
- 이를 해결하기 위해, 게임 오버 상태에서의 캔버스 클릭/터치는 무시하도록 변경하고 오직 키보드 `Space` 입력이나 UI 상의 `RESTART` 버튼을 명확히 클릭했을 때만 재시작되도록 조작 로직을 격리 및 개선했습니다.

### 7.2 UI 버튼을 통한 재시작 시 BGM 재생 복구
- **BGM 핫픽스**: UI 상의 `RESTART` 버튼을 눌러 수동으로 게임을 재시작(`restartGame()`)할 때, 배경 음악(BGM)이 다시 재생되지 않고 무음으로 유지되던 버그를 패치했습니다. 재시작 파이프라인 내부에서 `this.audio.startBGM()` 호출이 정상적으로 연동되도록 수정했습니다.

### 7.3 보스전 상태에서의 물리 타이머 및 버프 갱신 보완
- **버그 핫픽스**: 보스전 상태(`BOSS_FIGHT`)에 있을 때, 스킬 쿨타임(Cooldown), 피버 및 아이템 버프 지속시간(Duration), 그리고 새의 대시 시 복원력을 제어하는 수평 슬라이드 백 오프셋(`xOffset`) 등 게임 갱신 루프 내부의 물리적/시간적 타이머들이 더는 정지하지 않고 원활하게 흘러가도록 보완했습니다. 이를 통해 보스전 도중 액티브 스킬 쿨타임이 멈추거나 무적 버프가 무한 유지되는 조작 및 물리 오류를 완전히 정상화했습니다.

### 7.4 게임종료 후 복귀/재시작 모바일 접근성 및 아이템 아이콘 깨짐 개선
- **복귀/재시작(RESTART) 버튼 정상화**: 기존에 `div` 태그로 구현되어 일부 모바일/터치 브라우저(iOS Safari 등)에서 클릭이 무시되거나 전혀 동작하지 않던 재시작 및 상점 열기 인터페이스를 정식 HTML `<button>` 태그로 변환하여 모바일 환경 터치 접근성을 완전히 회복했습니다.
- **이모지 아이콘 깨짐 핫픽스**: 버튼 내부에 사용되던 롤리팝(`🍭`) 이모지가 일부 단말기 폰트 사양 문제로 깨져서 엑스 박스(`☐`)로 노출되던 현상을 해결하기 위해, 모든 환경에서 일관되게 고해상도로 드로잉되는 인라인 SVG 사탕 컴포넌트(`LollipopIcon`)를 신설 및 대체했습니다.
